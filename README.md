# ThoughtFlow v2 🚀

ThoughtFlow v2 is a secure and scalable real-time chat application built using the MERN stack. This upgraded version introduces production-level backend optimizations like Redis caching, session storage, rate limiting, and encrypted authentication for improved performance and security.

## ✨ Features
- 🔐 JWT Authentication & Authorization
- ⚡ Redis-based Recent Message Caching
- 🛡️ Rate Limiting & Secure APIs
- 💬 Real-time One-to-One & Group Chats
- 🔒 Encrypted Communication
- 📦 Session Storage Optimization
- 🌐 Fully Deployed on Vercel & Render
- 📱 Responsive React Frontend

## 🛠️ Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Caching:** Redis
- **Authentication:** JWT, bcrypt
- **Deployment:** Vercel, Render

## 🚀 Installation

```bash
# Clone repository
git clone <repo-link>

# Install frontend dependencies
cd frontend
npm install

# Install backend dependencies
cd ../backend
npm install

# Run frontend
npm run dev

# Run backend
npm start
```
